# 画面定義書 (Screen Specifications)

## 1. 画面一覧と主要機能

### 1.1 ホーム画面 (Home)
* **目的**: ゲームの入り口。
* **主要要素**:
    * プレイボタン（ランダムマッチ開始）
    * 「友だちと対戦」ボタン（合言葉入力へ）
    * ユーザープロフィール要約（名前、現在のレート）
    * リーダーボード（TOP10）へのリンク
    * ルール説明（チュートリアル）へのリンク

### 1.2 マッチング待機画面 (Matching)
* **目的**: サーバーが対戦相手を見つけるまでの待機状態。
* **主要要素**:
    * マッチング中アニメーション（ローディング等）
    * 経過時間のカウントアップ
    * 「キャンセル」ボタン（ホームへ戻る）
* **遷移条件**: 相手が見つかり次第、自動的に「対戦画面」へ遷移。

### 1.3 合言葉マッチ入力画面 (Private Match Entry)
* **目的**: 特定の相手と遊ぶための合言葉の設定。
* **主要要素**:
    * 合言葉（Room ID）入力フィールド
    * 「部屋を作る / 参加する」ボタン
* **形態**: モーダルまたは独立したサブ画面。

### 1.4 対戦画面 (Game)
* **目的**: メインのゲームプレイ。
* **主要要素**:
    * **共有盤面**: 16x16のグリッド
    * **プレイヤー情報**: 自分のライフ(❤️)、スコア、相手のライフ、スコア
    * **ターンインジケーター**: 「自分のターン」「相手のターン」の明示
    * **10秒タイマー**: 視覚的なカウントダウンバーと数字
    * **フラッグ表示**: 自分が立てた爆弾目印（自分にのみ表示）
* **演出**: 残り3秒からの赤色点滅、ダメージ時の画面シェイク。

### 1.5 リザルト画面 (Result)
* **目的**: 試合結果の確認と次のアクション。
* **主要要素**:
    * 勝敗の結果（WIN / LOSE / DRAW）
    * 最終スコアの比較
    * レートの変動値（+25 / -15 等）
    * 「もう一度遊ぶ（再戦リクエスト）」ボタン
    * 「ホームに戻る」ボタン

### 1.6 プロフィール・戦績画面 (Profile)
* **目的**: 自分の成長記録の確認。
* **主要要素**:
    * 累計勝敗数、勝率
    * レート推移グラフ
    * 直近10試合の履歴（日時、相手、勝敗）

---

## 2. 画面遷移フロー



1. **Home** → **Matching** (ランダム選択時)
2. **Home** → **Private Entry** → **Matching** (合言葉選択時)
3. **Matching** → **Game** (マッチング成立時)
4. **Game** → **Result** (決着時)
5. **Result** → **Home** または **Matching** (再戦時)

---

## 3. 例外時の画面挙動
* **接続遮断**: 対戦中に WebSocket が切断された場合、対戦画面上に「再接続中...」のオーバーレイを表示。
* **相手の退出**: 相手がリザルト画面を見ずに切断した場合、リザルト画面に「相手が退出しました」と表示し、再戦ボタンを無効化。
